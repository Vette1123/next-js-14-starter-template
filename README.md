# Sadge Template

## Introduction

[Sadge Template](https://github.com/Vette1123/Next.js-starter-template) is a custom Next.js starter template for new web projects.

You can also find Sadge Vite template [here](https://github.com/Vette1123/vite-starter-template)

## Features

- Dark theme with `next-themes`
- TypeScript support
- ESLint and Prettier
- Absolute imports
- Husky pre-commit hooks
- Tailwind CSS
- Shadcn-ui components

## Prerequisites

You need the following installed on your machine:

- [Node.js](https://nodejs.org) (18.17 or later, the minimum for Next.js 14)
- [npm](https://www.npmjs.com/get-npm) or [Yarn](https://yarnpkg.com) or [pnpm](https://pnpm.io/installation) (preferred)

### Usage `create-next-app`

To create a new project from this template, use `create-next-app` with the `-e` flag:

```bash
npx create-next-app -e https://github.com/Vette1123/next-js-starter-template --use-pnpm
```
